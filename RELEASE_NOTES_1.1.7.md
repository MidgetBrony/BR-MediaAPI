# BR-MediaAPI 1.1.7

- Adds lifecycle-safe visual overrides for existing BOXROOM media without replacing identity, saves, pickup, placement, inspection, or launch behavior.
- Supports distinct shelf, loose, held, and inspection presentations.
- Exposes native presentation centres and bounds for reliable model alignment.
- Preserves BOXROOM placement previews and player-controlled object scaling.
- Reapplies native inspection visuals after BOXROOM activates the inspector and positions them in front of the camera.
- Keeps native override handling isolated from Books and other generic custom-media types.
